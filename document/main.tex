\textbf{Document status.} This integrated working specification supports team
discussion of responsibilities and shared contracts. Team approval and the
professor-required B submission hierarchy remain open. The simple
\texttt{article} format is an editorial choice for a maintainable shared source.

Aligned semantics from the current team draft appear as ordinary prose.
\textbf{OPEN} marks source conflicts or missing decisions.
\textbf{PROPOSED} marks candidate closures from Home-side discussion and analysis.
Logical contract meanings guide integration while exact schemas and deployment
choices await team decisions.\sourcecite{draft}\sourcecite{commission}

The current project name is SPIRA. The full title above follows the user's
6 November naming decision. Settle 3.2 is retained as historical design
provenance for the current product baseline.\sourcecite{baseline}
