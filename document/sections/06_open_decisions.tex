\subsection{Small implementation probes}

\proposed{The following probes can test the shared contracts during implementation. They are scenario-derived validation candidates.}

\begin{enumerate}
\item A connector smoke test requests a kettle plug transition from on to off and checks independent off readback.
\item A first-guest probe supplies raw doorbell and doorlock events, evaluates the agreed rule, checks task eligibility, requests living-room pink lighting, and returns effect evidence from independent simulator state.
\item A negative verification probe accepts a command while retaining the previous simulator state. Readback must expose the mismatch.
\item A manual-TV-off probe applies an atmosphere task, supplies a later user-originated off event, and checks ownership loss and skipped restore with an explicit reason.
\end{enumerate}

These probes leave the event rule, concrete connector schema, hardware, and transport subject to the decisions above. Their specification records intended checks. Execution and results belong to later implementation work. \sourcecite{draft}\sourcecite{home}
